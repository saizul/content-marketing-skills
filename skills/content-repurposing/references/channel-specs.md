# Channel specs and conventions

Limits change; check the platform's help pages when precision matters.

| Channel | Hard limits | What works |
| --- | --- | --- |
| LinkedIn post | 3,000 characters | Hook in the first line (about 140-210 chars show before "see more"), short paragraphs, 0-5 hashtags at the end, link in first comment if reach matters |
| X post | 280 characters for standard accounts (longer posts need a paid plan); every URL counts as 23 | Post 1 must work alone; one point per post; link in the last post |
| Newsletter | Subject: no hard limit, but inboxes cut around 40-60 chars (less on mobile); preview text shows roughly 35-140 chars depending on client | One primary CTA, personal opener, takeaways instead of the whole article |
| Short video (Reels / Shorts / TikTok) | Shorts up to 3 minutes, Reels and TikTok longer; 45-60 s is a safe target for a single point | Hook in under 3 s, captions, one idea per beat, spoken CTA |

## Mapping a post to channels

| Post element | LinkedIn | X thread | Newsletter | Video |
| --- | --- | --- | --- | --- |
| Strongest number | hook | post 1 | subject option | hook |
| Intro problem | context line | - | opener | setup |
| H2 sections | 3-5 numbered points | 1 post each | 3 takeaways | max 3 beats |
| Examples / case | one line per point | the mini case post | one sentence | B-roll |
| CTA / URL | first comment | last post | button/link | "link in profile" |

## Voice

- Write in the first person if the source does; keep the author's terms and examples.
- Cut, do not compress: a thread with 5 clear posts beats 12 dense ones.
- Never add claims, numbers or quotes that are not in the source.
- Default to no emoji; when allowed, use one or two as signposts, not decoration.
